# End-to-end-UK-visa-sponsored-project
What tools  and skills do UK employers who offer data analyst visa sponsored jobs look for ? This is an end to end project featuring web scraping (python), analysis (SQL), and dashboard (Power BI)
#UK Visa sponsorship Data Analyst Jobs : skills and Tools analysis across different UK locations 
**problem Statement** Oversea applicants need to know what the UK employers that offer visa sponsorship ask for in data analyst roles. 
**what I need to do** collect 100 to 150 job postings from sponsoredjobs.uk with python requests and beautiful soup, clean using pandas, query in sql and build a 3 page dashboard.
**Questions to be answered**
* what are the top tools employers ask for by location? dim tool,evel(main or nice to have) bar chart of the top 10 tools split by level 
* what skills are requested the most and do they change by experience dim skill, seniority , heatmap or stacked bar 
* how much experience is asked for
* which employers and sectors hire frequently and how recent are the postings . company, sector and date posted , chart of the top 10 employers bar , line by week
